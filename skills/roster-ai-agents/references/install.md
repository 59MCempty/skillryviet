# Cài đặt template Roster

1. Chép thư mục skill vào `.agents/skills/roster-ai-agents/` của dự án.
2. Yêu cầu agent dùng `$roster-ai-agents` cùng dữ liệu VI/EN và ảnh sản phẩm.
3. Tạo bản xuất mẫu bằng `node scripts/build-site.mjs` từ thư mục skill hoặc truyền đường dẫn dữ liệu và đầu ra để xuất bản tùy biến.
4. Mở trực tiếp HTML. Đổi sang EN trong header hoặc thêm `?lang=en` vào URL của file.
