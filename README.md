# Skillry Template Studio

Workspace mới, hoàn toàn độc lập dùng để thiết kế, đóng gói và kiểm thử **Front-end Template Skills** theo chuẩn `skillry.dev` × `anthropics/skills` (`frontend-design`).

## Cấu trúc thư mục

- `SOP-TAO-TEMPLATE-SKILL.md`: Quy trình chuẩn 6 bước (kèm 3 Cổng Kiểm Duyệt).
- `skills/`: Nơi lưu trữ các Skill đã đóng gói chuẩn (`SKILL.md`, `references/`, `templates/`, `scripts/`).
- `templates/`: Nơi dựng nháp và xem trước bản mẫu (`demo.html`) trước khi đóng gói thành Skill.
- `references/`: Tài liệu tham chiếu kỹ thuật chung (font tiếng Việt đã test, bảng màu, mẫu tham khảo).
